Download Guava

Early access · macOS 14 Sonoma or newer

Download Guava.dmg

Install it

  1. Open Guava.dmg from your Downloads folder.
  2. Drag Guava onto the Applications folder in the window that appears.
  3. Open Guava from Applications or Launchpad. You can eject the disk image afterwards.

"Apple could not verify Guava" when you first open it? Early-access builds aren't notarized by Apple yet. Open System Settings › Privacy & Security, scroll down to the message about Guava and click Open Anyway, then confirm. You only need to do this once.

After installing

  • The first time Guava opens Desktop, Documents or Downloads, macOS asks for permission. Click Allow.
  • For the cleanup tools to see everything, add Guava under System Settings › Privacy & Security › Full Disk Access.
  • To use the AI bar, pick Claude or Ollama in Guava's Settings (⌘ ,). See Help.

Uninstall

Drag Guava from Applications to the Trash. Guava keeps its settings in ~/Library/Preferences and your API key in your Keychain; delete those too if you want nothing left behind.
