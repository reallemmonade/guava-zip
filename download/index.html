Download guava.zip

Early access · macOS 14 Sonoma or newer

Download guava-zip.dmg

Install it

  1. Open guava-zip.dmg from your Downloads folder.
  2. Drag guava.zip onto the Applications folder in the window that appears.
  3. Open guava.zip from Applications. You can eject the disk image afterward.

"Apple could not verify guava.zip" when you first open it? Early-access builds aren't notarized by Apple yet. Open System Settings › Privacy & Security, scroll down to the message about guava.zip and click Open Anyway, then confirm. You only need to do this once.

guava.zip will trigger a few macOS permission prompts (folders, controlling Finder, data from other apps, background items, notifications, Full Disk Access). See what each one means and what to click.

After installing

  • The first time guava.zip opens Desktop, Documents or Downloads, macOS asks for permission. Click Allow.
  • For the cleanup tools to see everything, turn on full access from the card guava.zip shows on first launch.
  • To use guava.zip AI, add an Anthropic API key or pick Ollama in Settings › Assistant (⌘ ,). See Help.

Uninstall

Drag guava.zip from Applications to the Trash. To remove everything else, also delete ~/Library/Preferences/zip.guava.app.plist, ~/Library/Application Support/Guava (data and API key) and ~/Library/LaunchAgents/zip.guava.junkcheck.plist.
